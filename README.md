# 作文题材向导 · 初二

四步选定**体裁 → 领域 → 切口 → 情感**，给出固定的题目组合与写作支架。
单文件 HTML，无依赖、无构建、离线可用 —— 下载下来双击就能用。

[在线打开](https://letuluvme-hub.github.io/composition-topic-guide/) ·
[打开怎么用](#怎么用)

## 它解决什么

初二学生卡在作文上，通常不是"没素材"，而是**不知道从哪儿下笔**。
这个工具把"下笔"拆成四个可以点着选的问题，每一步都告诉你**选了这一项之后，你真正能拿到几篇**。

每给定题会给出：

- 一句话立意（开头结尾都要绕着它写）
- 3–5 条能用上的真实素材
- 4 步骨架（开头 / 主体 / 转折 / 结尾各干什么）
- **翻车点** —— 写之前扫一眼，能省掉一类最低级的失分
- 可切换的主角槽位（真实素材比好题目重要）

选定后进入写作台：40 分钟倒计时、按体裁给的开头/主体/结尾字数配额、一键复制整份写作单。

## 怎么用

1. 依次点第 1–4 步。每一步都可以点「不限」—— 四维交叉后命中数会急剧变小，
   必须能说"这一步我还没想好"，否则会被逼进死路。
2. 走完第 4 步直接出题；也可以在任意一步点「按这几步出题」提前看结果。
3. 结果页的每张卡都会标明它**完全符合 / 差一项 / 差两项以上**，以及具体差哪一步。
4. 点「就写这篇 →」进写作台开始写，或先「☆ 收藏」攒着考前背。

同一组选择永远给出同一批题（不是随机的），考前可以把喜欢的那几组练熟。
想换一批就点「换一批」，题会在同一条路上轮换。

## 关于"一篇都没有"

四个维度交叉有 **4400 种组合**，题库有 **462 篇**，所以实测下来：

| 情况 | 占比 |
|---|---|
| 严格四项全中 0 篇 | 90.4% |
| 严格命中 1 篇 | 8.7% |
| 严格命中 2 篇 | 0.9% |

这种情况占多数，是题库规模决定的，不是筛选出错。所以工具的做法是**按符合度排序补齐**，
并且**如实说明补进来的是差几项** —— 不会把差两项以上的题说成"最接近你"。
选项卡上的数字也是严格命中数，不是虚标。

想让精确命中变多，只有两条路：压缩维度空间（比如让"切口"依赖体裁），
或者继续补题库。这是个产品取舍，见下面的"已知取舍"。

## 自己加题

右上角「题材库 → 加题」，一行一篇，竖线分隔：

```
我家的小黄狗 | g记叙 | d家庭亲情 | c一件旧物 | e温暖感动
半命题：《____的味道》 | 记叙 | 成长烦恼 | 一个第一次 | 成长领悟
```

后四列可写代码（`g`/`d`/`c`/`e`）或中文名，认不出的行会逐行报错，不会把整批丢掉。
重复的题目按标题自动去重。

> 注意：**自加题目只存在当前设备的这个页面里，刷新或关掉就没了。**
> 如果要长期用，建议先把题目整理进题库代码。

## 开发

```
index.html          全部内容：样式 + 题库数据 + 逻辑
tools/harness.mjs     Node 下的最小 DOM 桩，用来在命令行跑 index.html 的内联脚本
tools/lint.mjs        语法检查 + 悬空引用扫描
tools/checks.mjs      行为检查（计时器生命周期、导入去重、槽位、无障碍…）
tools/bench.mjs       results() 新旧算法等价性 + 性能对比
tools/check-prod.mjs  生产模式下不应暴露写接口
```

```bash
node tools/lint.mjs        # 语法检查 + 悬空引用扫描 + 遗留标记
node tools/checks.mjs      # 43 项行为检查
node tools/bench.mjs       # 13200 组新旧算法等价性 + 性能对比
node tools/check-prod.mjs  # 生产模式不暴露 __T
```

（路径参数可省略，默认读仓库根目录的 `index.html`。）

页面内也有一份自检：启动时校验字段完整性、id 重复、每个维度值是否都被用到，
结果挂在 `window.__ZXZ`。

调试钩子 `window.__T` **只在 `index.html?debug` 或 localhost 下挂载** ——
它里面有能改题库、落盘的写接口，不该在正常页面上开着。

## 已知取舍

- **题库填充率低**：见上面的表格。这是数据规模问题，不是逻辑问题。
- **同组合只出 1 张卡**：结果页刻意不让两个卡片四个维度完全一样（那对她等于只给了 1 个选择）。
  代价是严格命中 2 篇时也只出 1 张精确卡，界面会明确写出折叠了几篇。
- **自加题目不持久化**：见上面。
- **全 `var`、单文件**：还没做 ES module 化和数据外置。数据占了脚本的 85%
  （462 行、每行约 450 字符），diff 不好 review —— 这是最该动但还没动的一块。

## 无障碍

- 全局 `:focus-visible` 焦点环；自绘的步骤条、素材项、侧栏条目都有 button/checkbox 语义和键盘操作
- 抽屉是真正的模态：`role="dialog"` + `aria-modal` + Tab 焦点陷阱 + Esc 关闭 + 焦点归还
- "跳到主要内容" 跳过链接；`prefers-reduced-motion` 已处理
- 深色配色，`color-scheme: dark` 已声明（未做浅色主题）
