# 概念 v「以此为业」的追加标签（overlay：并入已有标签，不覆盖）
#
# 为什么加第 22 个概念：全量标注后实测发现《传统手艺》前 5 条是
# 「阳台上还晾着两块抹布」「换下来的旧灯泡她没扔」「抽屉最里层压着一部
# 屏幕发黄的旧手机」—— 全库搜「破旧+重复+还在继续+很小+具体物」，
# 每一件旧东西都命中。缺的不是形容词，是「这个人以此谋生」这一层。
# 21 个概念里没有任何一个能区分「手艺人在干活」和「一块抹布在滴水」。
#
# 收录标准：这个人靠这件事拿到收入/它是他的营生/它有专门的行话和工具。
# 不收：家里自己做的（奶奶织毛线、外婆腌酱）、买的旧物（缝纫机、座钟）、
#       公共设施（绿邮筒、青砖）、以及只是长得像工具的物件。
