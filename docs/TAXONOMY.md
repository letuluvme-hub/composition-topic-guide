# 素材语义标注 · 概念体系

> 状态：**已实现**。1879/1879 标注完成，22 个概念，检索已接进 `index.html`。
> 本文保留设计依据与踩过的坑 —— 下面每一条「实测」都是当时量出来的，
> 改体系之前请先读那些数字。

标注 1879 条素材之前先定这个。**体系定错了，1879 条标签就白标**，
所以这一节是整个语义层的地基。

## 设计前提（数据实测）

- 1879 条素材零重复，10.6 万对立意相似度全部 < 0.3 —— **素材本身质量很好，不模板化**
- 素材几乎全是「某个东西微微偏离常规 / 没人注意 / 但一直在那儿」的具体瞬间：
  - 铁皮饭盒里饭票按日期排好，最后一张是三年前的暑假
  - 那周的值日我扫得特别慢，一直扫到没人催我
  - 领奖时第三名的奖状纸比一等奖的浅一个色号
  - 有个租客在下面贴了纸条，第二天没人回
  - 桌上没人笑，爷爷的筷子停在半空里没落下来
- 关键词检索对抽象题**系统性失效**（实测 7/7 抽象题整句命中 0 条）
- n-gram 模糊匹配**比不搜更糟**：它自信地返回错的东西
  （《记忆里的那张脸》→ 命中「那张」→ 返回「我的那张夹在英语书里」）

结论：概念必须按**「这个瞬间在作文里起什么作用」**设计，
不能按「素材里有哪些词」设计 —— 后者就是正则打标签，结果已实测是垃圾。

## 三条硬性约束

1. **标签要可解释。** 每条素材在界面上要显示它为什么被选中。
   embedding 做不到这一点（相似度是个黑箱数字），标签可以。
2. **概念要少。** 超过 30 个就没法当界面上的筛选芯片用了。
   原定 21 个，**最终 22 个** —— 多出来的 E3 是被实测逼出来的，见文末。
3. **多标签，但要有主次。** 一条素材通常 1–4 个概念，全打上等于没打。

## A 组 · 与他人的关系

> 这一组是抽象判断题的主要着力点。《不拘一格的美》全靠这一组。

| id | 概念 | 收什么 | 不收什么 | 数据里的例子 |
|---|---|---|---|---|
| A1 | **与常规不同** | 这个瞬间里有人/有事偏离了周围人的做法 | 只是"我"一个人的行为、没有人做参照的 | 「早读时整排都在说」的反面：我那句话没人跟着说 |
| A2 | **唯一 / 只有一次** | 明确出现"只有、就、唯一、一共"这类排他 | "很少"但没说排他的 | 「台下几十个家长里没有一个人举手机，只有我一个人举了」 |
| A3 | **被忽略 / 没人注意** | 有人或有事在场但始终没被看见 | "没人"的泛用（下雨没人这种天气描写不算） | 「贴在墙上一百天没人撕的那张通知」 |
| A4 | **被否定 / 被排除** | 有明确的反对、否定、劝退、被踢出去 | 没有人反对，只是没成功 | 「后排有人小声说这不是抄的吧，那句话声音没压住」 |
| A5 | **被看见 / 被记住** | 有明确的注视、发现、被留下 | 只是恰好在场 | 「手机里报名成功的截图我设成了收藏，列表里没放出来」 |
| A6 | **别人跟着变** | 一个行为/说法在人群里扩散 | 群体的一致作息（那是背景不是事件） | 「最早是隔壁组学我的，后来早读时整排都在说」 |

**A1 是最容易被标滥的一个**（我上一版正则就把「买菜的人不多，但每个人都不着急」误标成了它）。
标注时要严：**必须能指出"周围人原本会怎么做，而这次不同"**。指不出来就别给 A1。

## B 组 · 时间与重复

| id | 概念 | 收什么 | 数据里的例子 |
|---|---|---|---|
| B1 | **重复了很多次** | 同一件事发生了很多遍，或持续了很多天 | 「四十天里我有一周没管，第41天开盖时香味从后门一直飘到楼梯口」 |
| B2 | **一个具体的时间点** | 出现确切数字/天数/「第几天」 | 「第六十一天纸箱不见了」 |
| B3 | **后来变了** | 有明确的前后对照 | 「菜场改成快递点的那三个月」 |
| B4 | **没停 / 还在继续** | 到素材结束时仍然在做，没有结果 | 「第二天杂货铺照旧九点半关灯」 |

**B1 和 B4 一定要分开**：B1 是"做完了/做过很多遍"，B4 是"还在做、没有下文"。
《那些不起眼的坚持》这类题全靠 B4。

## C 组 · 状态

| id | 概念 | 收什么 | 数据里的例子 |
|---|---|---|---|
| C1 | **破旧 / 不整齐** | 磨损、褪色、歪、破、锈、掉漆 | 「侧面的出水口结着白色的垢，指甲刮下来是硬的」 |
| C2 | **慢** | 明确写出慢 | 「那周的值日我扫得特别慢」 |
| C3 | **静 / 没声音** | 突然安静、没人接话、声音变轻 | 「她下课回来问全班谁见过这样一根棍子，教室里一下子静了」 |
| C4 | **很小 / 不起眼** | 明确的"小、少、只一点点" | 「便利店门口的伞架只剩两把」 |

C1 单独拿出来是因为**《不拘一格的美》经常要靠"不美的东西美"来落地** ——
「第三名的奖状纸比一等奖的浅一个色号」就是这条。

## D 组 · 载体（可放大看的具体东西）

| id | 概念 | 收什么 | 判别力 |
|---|---|---|---|
| D1 | **具体物件** | 出现可拿可摸的物 | **判别力低**（约 40% 素材都有），只作次要标签 |
| D2 | **声音** | 喊、说、念、笑、安静、响 | 中（用于"记忆里的…"这类题） |
| D3 | **身体动作** | 手、脚、牙、背、停顿、姿势 | 中 |
| D4 | **字迹 / 笔迹** | 手写、签名、改过、笔迹轻重 | **判别力高**，写"记忆/证据/这个人"时极有用 |
| D5 | **数字** | 任何计数、分数、个数 | 中 |

D 组是"怎么写"而不是"写什么"，检索时权重应该低于 A/B 组。

## E 组 · 冲突

| id | 概念 | 收什么 | 数据里的例子 |
|---|---|---|---|
| E1 | **规矩 / 要求** | 有明确的规则、规定、要求在起作用 | 「比赛规则是各背五个，我准备了纸条，爸爸什么也没准备」 |
| E2 | **第一次** | 明确的第一回 | 「第一次自己开锁，手指抖了三次」 |
| E3 | **以此为业** | 有人靠这件事拿到收入，有专门的工具和行话 | 「工具箱里有三百来把伞骨，靠一根旧皮筋整整齐齐绑着」 |

**E3 是标完 1879 条之后才加的，不在原设计里。** 原设计 21 个，全量标注后实测
《传统手艺》前 5 条是：

> 阳台上还晾着两块抹布 / 换下来的旧灯泡她没扔 / 抽屉最里层压着一部屏幕发黄的旧手机

因为那一档用的是「破旧+重复+还在继续+很小+具体物」—— **凡是旧的小的都命中**，
而 21 个概念里没有任何一个能区分「手艺人在干活」和「一块抹布在滴水」。
E3 收 90 条（占比 4.8%），加进去之后第 1 条变成「三百来把伞骨」，
第 2 条变成「他的摊子在理发店和杂货店中间，从开春到入冬没挪过」。

收录标准：靠这件事拿到收入 / 它是他的营生 / 它有专门的工具和行话。
不收家里自己做的（奶奶织毛线、外婆腌酱）、买的旧物（缝纫机、座钟）、
公共设施（绿邮筒、青砖）。`data/mat-tags-v.txt` 是 overlay，只做追加不覆盖。

## 检索怎么用这套标签（实现记录）

**原设计是词表，实测被否掉了。** 原来打算用「词 → 概念」的映射表自动化，
`"美" "独特" "别致" … → A1 A2 C1`，理由是「规则就能算出来，不需要模型」。
实测《不拘一格的美》7 个关键词最后只映射出 **1 个概念（A1）**，单概念检索出来的是：

> 她来那天没穿家长会上穿的那件深色外套

跟这题毫无关系。而这个题真正需要 **5 面**：与常规不同 + 唯一 + 被忽略 + 被看见 + 破旧
（"不美的东西美"）。**「美」这个字本身推不出「破旧」**，所以映射只能手写。

实现改成了**题目档**（`data/topic-profiles.txt`，16 组），每档写死 `c`（调哪些概念）
和 `core`（哪个是门槛）。档是手写的，但不是拍脑袋 —— 每条都标了为什么这么写、
早期版本错在哪。

### 三条实现里才想清楚的规则

**① 打分顺序：先命中面数，再稀有度。** 稀有度只做同分时的微调。
踩过的坑：最早把稀有度加权分当主键，而 E1「唯一」只占 3.5% 却拿满 1.0 权重，
**任何带「唯一」的素材压过其余全部结果**。

**② 门槛是硬排除，不是降权。** 这一条是整个检索质量的关键。
`c` 里混着两类概念：

| 类型 | 例子 | 占比 |
|---|---|---|
| 判别性 | E3 以此为业 4.8% / E2 第一次 2.7% / B2 具体时间点 2.3% | 低 |
| 通用描述词 | D1 具体物 24.7% / B1 重复 19.6% / C1 破旧 16.5% / B4 没停 9.5% | 高 |

通用描述词凑齐三四个太容易。抹布那条素材同时命中 破旧+重复+还在继续+具体物，
**加权覆盖率还是 100%，降权救不回来**，只能设「至少命中 1 个判别性概念」的硬门槛。
门槛取值原则：**这一档里「不命中就说明根本不切题」的那一个概念**。

门槛的效果是可量的（10 个题里抽样）：

| 作文题 | 无门槛候选 | 有门槛候选 |
|---|---|---|
| 规则该不该被打破 | 1167 | **64** |
| 传统手艺 | 1076 | **90** |
| 第一次上台 | 1123 | **51** |
| 那些说不出口的小情绪 | 658 | **237** |

**③ 一个词只能属于一档。** 「传统」同时在规则档和手艺档里、「第一次」同时在
勇敢档和第一次档里 → 两档并集 = 8 个概念混在一起被稀释，
**值日表这种无关素材排到了第一**。并集比没命中更糟。

### 保留关键词搜索

概念检索和关键词检索**不混用**：用户打了词或点了线索切片就整体切到关键词模式。
理由是如果「既按概念筛过又按词筛过」，那「没命中」到底是哪一环造成的就说不清了。
搜具体东西（「饭票」「闹钟」「黑板」）关键词明显更好用。

### 概念芯片可手调

题目档是手写的，一定有不准的时候。所以每个概念都是可点的芯片，显示
「库里有这个概念的有几条」，门槛概念额外标「门槛」。改过之后出现「↩ 回到题目推荐」。

## 验收标准（标完之后必须过的四关）

1. **覆盖**：≥ 90% 的素材至少带 1 个概念 → **实测 100%（1879/1879）**
2. **精确**：随机抽 60 条人工复核，A1 的误标率必须 < 10%
   （A1 是最容易标滥的，单独卡）→ **未做，见文末「已知不足」**
3. **可解释**：任取 10 个抽象题，每个题取前 10 条，
   人工判断"这些素材写这个题合不合适"，合格 ≥ 7 条
   → **9/10 的档达标，《记忆里的那张脸》不达标，见文末**
4. **不倒退**：现有 43 + 62 项检查全绿，关键词搜索仍然保留
   → **43 + 136 全绿**（136 里含 71 项语义层新检查）

## 标注怎么做

我作为模型逐条读、逐条标，**分 7 批共 1879 条**（`data/mat-tags*.txt`）。
标签是**这个瞬间在作文里起什么作用**，不是素材里有哪些词。
**没有用正则生成标签** —— 已经实测证明那是垃圾。

标注完由 `tools/check-tags.mjs` 兜底检查格式、字母合法性、序号连续性、
概念使用率，以及自相矛盾的组合（`a+c` 35 条、`a+f` 59 条、`g+i` 25 条
这类「同一件事两头都占」的组合会被点出来）。
`data/mat-tags-v.txt` 是 overlay：只往已有标签上追加字母，不覆盖
（补标 E3 时不能把原来认真标的几个概念清掉）。

### 分批带来的已知偏差

前两批平均 3.75 个标签/条，后面几批降到 2.23 个/条 —— 越标越保守。
这会让 A1 的分布**偏向素材库前半段**（前两批 A1 占 32%，
全库 A1 占 43.2%）。稀有度权重是从全库频率算的，
所以这个偏差没有消除，只是被平均掉了。要严格干净的话需要重标前半段，
我判断收益不足以重做 540 条，先记在这里。

## 已知不足（明确记下来，不藏）

1. **《记忆里的那张脸》仍然弱。** 检索出来的是「墙纸泡皱后翘起一小片」这类
   环境细节，不是"记得一个人的脸"。根因：**22 个概念里没有「一个人的样子/外貌」**。
   我当初问过「概念数够不够」——答案是不够。但这类素材在库里本来就很少
   （1879 条里以人的外貌为对象的极少），加概念也命中不了多少。
   权宜之计：这一档的 `note` 里写明了取法，靠界面上的芯片手调。

2. **验收第 2 关（A1 误标率 < 10%）没做。** 抽查 60 条人工复核这一步
   没有执行。A1 占了全库 43.2%，是最容易标滥的概念，值得单独抽一遍。

3. **题目档只有 16 组，且关键词是贪心匹配。** 没命中的题会老实返回 `null`
   并提示用关键词/线索，不会瞎猜 —— 但也意味着覆盖面有限。

4. **《真正的勇敢》结果偏散。** 素材库里"勇敢"多以「没人看见的坚持」的形式存在，
   `core='a'`（与常规不同）拦得不够紧，第 4–8 条更像"没人管我"而不是"勇敢"。

## 已经拍板的（原问题 → 现在的答案）

| 原来的问题 | 结果 |
|---|---|
| 概念数 21 个够不够？ | **不够，最终 22 个** —— 加了 E3「以此为业」（见上） |
| 要不要加人物关系标签？ | **暂不加**。标签量会涨 40%，且从检索失败案例看，瓶颈不在人物关系，在「这个瞬间起什么作用」这一层。 |
| E2「第一次」要不要降级？ | **不降级，反而升级成门槛**。「第一次」占 2.7%，判别力高，《第一次上台》这类题直接拿它当 core（候选从 1123 收到 51）。 |
